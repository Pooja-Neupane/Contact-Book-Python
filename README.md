# 📒 Contact Book – Python Project

A simple and interactive **Contact Book** developed in Python that allows users to **add**, **search**, **edit**, **delete**, and **display** contact details using a dictionary-based structure.

---

## 📌 Features

- ✅ Add a new contact with name, phone, email, and address  
- 🔍 Search for contacts by name  
- 📝 Edit existing contact details  
- ❌ Delete contacts  
- 📋 Display all saved contacts  
- ⚙️ User-friendly console-based interface

---

## 🧑‍💻 Technologies Used

- **Python 3.x**
- Console Input/Output
- `Dictionary` data structure for contact storage

---

## 🗂️ Data Structure Format

```python
contacts = {
    "John Doe": {
        "phone": "1234567890",
        "email": "john@example.com",
        "address": "123 Main St"
    },
    ...
}
